# 已知限制

## 环境

- `start.bat` 需要本机 Python 3；也可直接用 Chrome/Edge 打开 `index.html`。
- 默认端口 8762，占用则顺延 8763+。
- 完整验证于 Chrome；Firefox/Safari 预期可用未专测。
- 需要 Pointer Events（现代浏览器均支持）。

## 玩法

- 纯解压沙盒：无失败、无关卡、无排行榜（按需求定位）。
- 部分武器有冷却；暴走期间冷却大幅缩短。
- 大招需宣泄值满（约 100）。
- 卡通夸张暴力（刀钉、爆炸、燃烧），**无写实血腥**；按非恶心风格绘制。

## 存储

- 进度/设置/照片在 localStorage（`stress-tap-save-v1`）。
- 照片建议 ≤4MB，过大可能超配额。
- 「清空全部记录」不可恢复；请用导出备份。

## 技术

- 物理为街机手感，非刚体仿真。
- 后台标签可能被浏览器节流（已加计时器补帧）。
- 无联机、无账号、无云同步。
- 音效为 Web Audio 程序合成，非录音素材。

## 日志与隐私

- 服务端不记录请求体；照片不经过 HTTP 上传。
- 原图只存浏览器本地。
